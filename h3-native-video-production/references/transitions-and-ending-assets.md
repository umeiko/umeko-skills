## 淡黑再淡亮：保留两边真实动态

本例G10为1.25秒30帧，G11为2.5秒60帧，24fps。G10最后6帧亮度从1降到0，G11最初6帧从0升到1；端点都取到黑。两镜总时长仍3.75秒，不另塞黑场，也不重叠台词。先画完字幕，再整体淡黑，避免黑场上留下悬空字幕。

只变画面亮度；G10“想当年”的完整原声和尾音保留。自然说话超过旧的一秒要求时，用户已明确接受当前take，最终延到1.25秒，停止反复生成。不要为了转场再截半个音节。

## “一天后”不是剧情补帧

用户明确要求海绵宝宝经典时间卡的喜剧停顿。本例用内置imagegen新做波利尼西亚/tiki花纹竖卡，准确显示“一天后 / ONE DAY LATER”，放在G38与G40之间2秒。它是明确的叙事插卡，不冒充H3真实动态帧，也不是从海绵宝宝原片截出的素材。

配的是原创短打击音提示，没有伪造原动画旁白。要原版旁白时需使用实际提供的原素材；不能默认克隆配音。插卡期间暂停原配乐，检查前一句“那可是奶奶”的尾音在切卡前结束。

## 用户指定的MyGO ED：画面与声音一起1.5倍速

原链接：[BV1JM4y177od](https://www.bilibili.com/video/BV1JM4y177od/)，《栞（Shiori）》MyGO ED。此次公开可取视频是852×480，音轨48k；不能根据页面标注或播放质量选项声称取得1080p。媒体流真实解码时长约97秒，元数据取整显示98秒。

先保留原画、原音及SHA，再派生1.5倍速版本。视频 `setpts=(PTS-STARTPTS)/1.5`，音频 `atempo=1.5` 保持音高；只改其中一边会失步。原横画幅等比例适配到576×324，置于576×1024中间，上下留黑；不拉伸、裁掉原画信息或把黑边误当坏帧。

命令示例，FFmpeg可执行路径由目标环境提供：

```bash
ffmpeg -n -i source_video.m4s -i source_audio.m4s \
  -map 0:v:0 -map 1:a:0 -c copy original_ed.mp4

ffmpeg -n -i original_ed.mp4 \
  -vf 'setpts=(PTS-STARTPTS)/1.5,fps=24,scale=576:324,pad=576:1024:0:350:black,setsar=1' \
  -af 'asetpts=PTS-STARTPTS,atempo=1.5,aresample=48000' \
  -c:v libx264 -crf 17 -preset fast -c:a aac -ac 2 -ar 48000 -movflags +faststart ed_1p5.mp4
```

实际输出时按帧网格再核首尾。此次ED适配为1552帧/64⅔秒；最后一个白场帧为24fps量化延展，原片和首个候选均保留。这不允许用静帧顶替未生成的剧情。容器毫秒舍入曾比实际PCM多16个48k样本；应检查真实解码样本和目标剪辑范围，不按容器数字盲补静音或截声音。

片尾音乐是用户明确指定的追加内容。本例“剧情最后六秒原创配乐归零”仍执行，ED在剧情结束后另起；不要把旧的末六秒禁配乐规则错误应用成截掉整段ED。

## 明确授权的局部变速

G44原五秒、G46原四秒按用户要求二倍速，分别输出2.5秒和2秒；画面和原声共同变速。G45已合并进G43，不能因“G44～G46”字面范围再把G45插回去。其他对白仍原速，禁止把局部变速授权推广成全片任意加速。

分开记录 `source_frames`、`playback_speed` 和输出 `frames`，按输出帧重新累计全部剪接和字幕。24fps含分数秒时用48k音轨，每输出帧恰2000样本，可避免32k在1/24秒处不能整除的问题。最终本例5590帧、232.9166667秒、双声道每声道11180000样本，不再强凑旧234或240秒。

## 发布底纹：两个派生文件，共用同一母版

用户指定两份渠道底纹：`Bilibili Aomura_Umeko` 与 `小红书：UmekoLab科技工作室`。本例采用低透明度19度斜向重复文字，完整账号不被画边裁掉，避开主要字幕区域。浅色脸、深色衣服、夜景、字卡和ED黑边都看过后再定透明度。

保留干净母版和两张透明底纹PNG，各导出一个全新MP4；不要把第二个账号叠在第一个渠道版本上。只需叠画面时可 `-c:a copy`，再实际核AAC packet payload序列SHA与干净母版相同，确保没有换声或二次音频压缩。核真实帧数/fps/时长和关键原尺寸，把最终派生文件SHA分别绑定实际检查回执；按用户最新偏好直接复制到桌面输出文件夹，由用户自行播放，不自动打开或播放两份发布版。

本例还遇到FFmpeg默认MP4 movie timescale为1000，重封装后的edit list把232.9166667秒量化成232.916秒，解码少32个48k尾样本，尽管AAC payload序列完全一样。指定 `-movie_timescale 48000`，从精确干净母版重新取音轨、原底纹候选重新取视频并 `-c copy` 重封装，才恢复每声道11180000真实样本；无需再渲染画面或重编码音频。原失败候选保留，不能只用文件时长或AAC包SHA代替解码样本检查。

底纹用于降低直接搬运的便利，不能保证防盗。Release包保持来源说明和校验清单；不要把工作机绝对路径、访问凭据或临时下载签名URL塞进公开素材包。
