# 《爷爷，开战！》返工案例

记录依据：用户逐镜拒收、当时实际视频检查、原生声音证据和正式剪辑回执。此处移除了本机路径、进程与私有媒体。镜号用于定位同类问题，不是可直接套用的全局规则。下列“通过”指当时那个版本；后续用户改剧本不表示旧批准自动适用于新版。

## 身份、嘴形和声音

| 镜头/问题 | 观察与原因边界 | 最后采用的修法与验收 |
|---|---|---|
| G03盒子过大 | 道具比例压过孩子，参考图空间关系不合理 | 新首帧固定小型桌面盒；新r4孩子正面发声，爷爷全程背对，连续嘴形与实际原音通过。旧代念r3批准撤销，不回退。 |
| G03爷爷念孩子台词 | 台词识别对，但实际说话脸错误 | 让唯一说话孩子嘴部可见，爷爷背面隐藏嘴脸。不是仅改角色名字后凭ASR批准。 |
| G05相册变投影盒、双嘴 | 新r3约18–30帧把平面相册变成四家人投影盒；旧r2爷爷跟着孩子张嘴 | 新生成失败保留；采用旧r2真实动态孩子/平面相册近景，全158帧固定裁切，错误爷爷和盒完全排除，原音不变。不是恢复坏宽景。 |
| G06父亲说话时爷爷也动嘴 | 多角色同句嘴形错误 | 采用同源158帧父亲近景，固定裁切与原AAC/PCM相同，正式选段保父亲尾音。 |
| G07/G12后段长触角 | 首帧圆头不能保证后段身份；G07一次长负面清单同时提到触角/玩偶/照片，输出反而出现两球触角、蓝玩偶、相框白手套 | G12新r2全124头部逐帧通过；G07新r3保干净圆头参考，只写身份和招呼主动作，去掉整串异常对象词，全部158头顶连续检查通过。只记录关联，不声称单变量证明否定词必然反噬。 |
| G01生日版父亲长角 | 新r4原声句子正确，实际父亲头部出现三根突起且张嘴 | 用户要求剪片时采用真实动态孩子/礼物近景，全158帧排除父亲错头脸，保原音；不把好声音当画面通过。后来的赛博开场是另一版内容修订。 |
| G29转身长胡子/换装 | 原片转身后身份和衣服突变，用户明确核心拒收 | 严格双源真实动态选片：正确蓝袍挑战开头→已实际检查的G33安静孩子反应，保原G29声音。来源、范围、输出和原音绑定；没有重画胡子或冻结一张背影。 |
| G26/G27说话人都是爷爷 | 用户明确允许这两句改为爷爷本人口吻 | 同步将说话者、台词归属、声音描述和画面唯一嘴形改为爷爷，原生新r2通过。不能外推到全部镜头。 |
| G33孩子变老爷爷声音 | ASR正确仍可能音色错；新r3音高分析只作辅助 | 原生重生成孩子声，画面和尾音核对后，用户实际反馈“已是孩子口吻”才完成声音批准。承让/成绕的近音识别不确定保留。 |
| G31/G33把表情/背景提示念出 | G33已有d块，仍有中文标签外描述、对白错放soundscape和缺稳定SID | 英文舞台+固定SID+says+正文唯一原句d块+纯环境声字段，统一入口拦截未POST请求；实际新视频再核串读。不能归因成纯粹漏标签。 |

| G12/G14/G15石桌两人都在同侧 | G12/G14采用同源全幅水平反射，使小黄在右；G15孩子原左侧保相对反打 | 同时看相邻镜头、桌子/盒子/视线方向；无字镜头才适合整幅反射，已有文字不可随便镜像。 |
| G19/G21双人对战设备不对 | 新图与新r2明确一个横长透明盒、一个灰底、无隔墙，两位爷爷共享空间且左右固定 | 每个角色双脚在共同底面，不能两个独立盒或多层复制。G21r2右孩长冠仍拒收；只用原0–11正确同盒，之后真实左孩子反应近景排除错孩。 |
| G20付费技能意义不清 | 新r2明确右米衫向左发一个火球，命中蓝衫；蓝衫完整站立、焦黑后细烟，右方保持干净 | 实际发射/飞行/命中/变黑/冒烟连续看；不能只凭首帧已画火球。烟略越盒沿、局部肚黄按用户尺度接受。 |
| G22掏出孩子照片 | 用户给出“火焰冲击”卡参考，换成同一蓝金卡面与火球图，新r3通过 | 必须看到正确道具类别及技能图，不把随机小照片或乱码字当换肤/技能功能已实现。 |
| G25胜负结果相反 | 蓝袍法师站立，金甲爷爷仰躺、焦黑冒烟，新r2通过 | 站/躺、左右、衣服、烟和人数逐一核。 |

## 情绪、观察圈和结尾

| 镜头/问题 | 采用版本与原因 |
|---|---|
| 阿布形象不鲜明/错认邻居 | 用户明确阿布是末段六人全家队孩子；反戴砖红帽、黑圆框透明眼镜、墨绿背带裤、米白T，联动G43/G44/G45/G46/G47，不与小黄/小胖混用。 |
| G43/G45失亲背景却大笑 | 统一安静低落阿布与严肃同情的小胖。亲属去世情绪由实际表演体现，不只在字幕写悲伤。 |
| G44盒里人说话、外圈没人 | 旧动态拼接虽排掉说话脸，但观察圈消失/回归、尺度跳变，用户再次拒收。最终新r3一镜持续五孩子围观六家人，盒内闭嘴手垂；桌面自然遮挡远侧腿，无悬浮脚。全盒0–119连续检查和补充VAD空转写通过。 |
| G46意义不明/悬浮/多第七人 | 旧r2阿布腿脚悬盒沿、紫衣抬手开口；r3又新增盒顶成年人，均拒收。最终r4只拍六家人同盒的“活的全家福”，轻仰望画外阿布、脚落灰底、手垂，接失亲故事表达陪伴。 |
| G46画面对但声音错 | 用户明确无需再渲染，并指定复用G34。只换为已验证G34原生庭院声；新片视频包/RGB与已接受r4相同，声音样本与指定原源相同，VAD空转写。前一个其他声候选保留不用。 |
| G47/G48无关角色跟系统/别人说话 | G47最终选孩子说话→G45安静阿布真实反应；G48只留开头闭嘴全家，后切设备LED真实动态近景，保系统原声。两者来源范围锁定，旧失败候选不恢复。 |
| G35过于地狱；后续新版又不要G18 | G35整镜跳过后曾47镜234秒交付。后续独立开场新版按用户另指令再排除G18，保原片与旧计划；不以静帧/变速补回旧时长，不因此重生其他镜头。 |
| 前10秒抓不住人 | 用户后续改赛博家人直接介绍→G07，跳过G02–G06、压缩陪伴段；这属于剪辑/叙事设计修订，不是技术画质问题。新版本独立计划，不覆盖先前正式片。 |

## 最新清洁画面修复及尚待验收项

以下是用户最新要求与已确认问题，**不作为已经验证的修复成果**：

- G07新惊讶“爷爷！真的是你吗！”已实际全景/细节、原尺寸、全部头部和发声连续帧通过；爷爷背面静听。G11新2.5秒静默背面对远处足球也已通过，低信息ASR保留并用正确16k/VAD补充空转写。
- G09新4步原片约42–90帧出现白字黑边台词；G15旧原片72/120等帧也有台词。首帧和第96帧干净并不代表中间无字幕。一次加入短的“without subtitles or lettering”仍失败，G09下一版甚至产生黑字幕条，不能把这句提示词当保证。
- 再次生成将画面描述改为正向参考周围物理环境与 `unmarked appearance`，不提字幕对象；G09r4、G13r3实际全源底部、全景/细节、原尺寸与嘴形连续检查无字幕，原生整句和3秒/2秒尾音通过。该次也换了种子/简化提示词，不能宣称隔离证明某个单词必然有效。
- 同一写法并未保证G15：r3虽然去掉台词，又长棕色头顶突起与衣服字样，仍拒收；G10也仍生成字样。新参考/短句正在返工，**尚未验证**，不能按G09成功批量批准。
- G08/G10原生说话超出用户要求的2秒/2.5秒，保留超时源并进一步改短句；不切首尾音或改速度，后续新片仍待实际检查。
- 后期字幕需更大、更高、白字黑边，已在真实明暗画面做原尺寸40px/黑描边预览，逐镜避开盒子；这是样式预览，尚非新整片交付。最终输出仍须实际完整检查。

后续维护本表时，只有实际新视频和声音通过后才把对应项移入“采用修法”；保留原失败、推测和用户审美判断的边界。
